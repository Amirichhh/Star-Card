# Star Card — Telegram-бот

Бот-биржа коллекционных карт за звёзды Telegram (Stars).

## Установка

```bash
pip install -r requirements.txt
```

1. Получите токен бота у @BotFather.
2. Откройте `config.py` и укажите:
   - `BOT_TOKEN` — токен бота (или переменная окружения `BOT_TOKEN`)
   - `ADMIN_IDS` — ваш Telegram ID (узнать можно у @userinfobot)
3. Запуск:

```bash 
python3 bot.py
```

База данных SQLite создаётся автоматически в `data/star_card.db`.

## Что умеет бот

**Пользователи**
- Пополнение баланса встроенными звёздами Telegram (Stars, `XTR`).
- 🛍 Магазин карт — покупка у бота по текущему курсу, с поиском и постраничным списком
  (важно: список **не** заваливает чат сотнями сообщений — это компактная клавиатура).
- 📈 Биржа — топ карт по изменению курса за сегодня (курс живой: растёт при покупках,
  падает при продажах — как на крипто-бирже, плюс дневной максимум и % за 24 часа).
- 👤 Профиль — баланс, карты сгруппированы по видам (без простыни из 100 строк),
  общая стоимость портфеля, % прибыли/убытка, % изменения за сегодня.
- 📉 Автопродажа обычных карт боту по курсу — можно продать сразу несколько штук
  за один раз, курс после продажи проседает (проскальзывание).
- ⚗️ Улучшение карт (гача): выбираете сколько обычных карт "прокрутить", каждая
  попытка стоит от 15 до 50 ⭐ (первый час после запуска — дороже, шанс на
  легендарную карту выше; цена линейно снижается каждые 10 минут до базовой
  ставки 15 ⭐). Редкость выпадает случайно (redkaya/эпическая/мифическая/
  легендарная), затем — случайный конкретный арт этой редкости, если их
  несколько.
- 💸 Заявки на вывод звёзд.
- 🆘 Тикеты поддержки с двусторонним диалогом (открыты, пока пользователь или
  модератор не закроют).

**Модераторы** (назначаются админом)
- Просмотр и одобрение/отклонение заявок на вывод.
- Обработка тикетов поддержки (взять в работу / ответить / закрыть).
- `/moderator_help`

**Администратор**
- Создание базовых карт (фото, название, цена).
- Выпуск улучшений: цикл "редкость → фото → название → добавить ещё / опубликовать",
  можно выпустить сразу несколько артов на одну редкость. После публикации
  стартует "горячий час" гача-цен.
- Пауза/возобновление релизов улучшений в любой момент.
- Изменение баланса пользователя по ID/username (прибавить/убавить или задать
  абсолютное значение).
- Назначение/снятие модераторов, список модераторов.
- Управление обязательными каналами для подписки (добавление/удаление).
- Бан/разбан по ID/username.
- Чеки — промокод на звёзды по ссылке (можно ограничить число активаций).
- `/stats`, `/admin_help`

## Экономика (настраивается в `config.py`)

- `MARKET_COMMISSION` — комиссия при автопродаже карт боту (по умолчанию 7%).
- `RARITY_MULTIPLIERS` — во сколько раз ценность улучшенной карты выше курса
  базовой карты (редкая — минимальная наценка, легендарная — максимальная).
- `UPGRADE_LAUNCH_PRICE` / `UPGRADE_BASE_PRICE` / `UPGRADE_DECAY_MINUTES` /
  `UPGRADE_DECAY_STEP_MINUTES` — цена попытки улучшения и график её снижения.
- `RARITY_DROP_RATES` — базовые шансы выпадения редкости.
- `RATE_ALPHA`, `RATE_BUY_PRESSURE`, `RATE_SELL_PRESSURE`, `RATE_MIN_FACTOR` —
  параметры биржевого алгоритма курса.

## Важно перед продакшн-запуском

- Бот должен быть **администратором** во всех обязательных каналах, иначе
  проверка подписки не сможет получить статус участника.
- Замените `ADMIN_IDS` на свой настоящий Telegram ID.
- Рекомендуется запускать бота через systemd/supervisor/screen для постоянной
  работы (long polling).
